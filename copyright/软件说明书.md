## 一、软件概述

### 1.1 软件名称

羊群大整理小游戏软件 V1.0

### 1.2 软件用途

本软件是一款运行于移动端小游戏平台的休闲益智类分类整理游戏。玩家通过将
混合摆放的动物按品种归集到同一栏位，完成关卡目标，在过程中锻炼空间规划
与前瞻推理能力。

### 1.3 主要功能

1. **关卡生成与求解** —— 内置求解器，对每个生成的关卡进行可解性验证，
   确保发放给玩家的每一个局面都存在通关路径
2. **游戏进行** —— 栏位选择、群组移动、自动出栏判定、胜负判定
3. **辅助道具** —— 撤销、加栏、提示、牧羊犬、重排五类道具，
   其中提示与牧羊犬依赖求解器进行安全性校验
4. **难度管理** —— 程序化关卡生成，多档难度参数曲线
5. **广告展示管理** —— 广告频次控制、失败兜底、投放记录
6. **虚拟道具与权益管理** —— 商品目录、权益状态、发放时机决策
7. **虚拟货币系统** —— 多来源获取、每日额度、账本记录

### 1.4 运行环境

| 项目 | 要求 |
|---|---|
| 运行平台 | 移动端小游戏运行环境（Android / iOS） |
| 开发语言 | TypeScript |
| 渲染方式 | Canvas 2D |
| 运行时依赖 | 无第三方运行时库 |
| 屏幕方向 | 竖屏 |
| 网络 | 单机可运行，联网用于排行榜等可选功能 |

### 1.5 技术特点

**关卡可解性保证**：本软件区别于同类产品的核心技术点。关卡生成流程为
「随机布局 → 求解器验证 → 未通过则重新生成」，求解器采用深度优先搜索
配合状态规范化去重与启发式排序。因此软件不会向玩家发放无解局面，
且在玩家操作导致局面不可解时能够即时检测并提示。

## 三、操作说明

### 3.1 界面构成

游戏主界面自上而下分为四个区域：

1. **状态栏** —— 显示当前关卡、剩余动物数量、当前得分、虚拟货币余额
2. **提示条** —— 仅在局面不可解时出现，提示用户使用撤销或重排
3. **栏位区** —— 游戏主区域，显示所有栏位及其中的动物
4. **道具栏** —— 五个道具按钮，显示各自可用状态

【截图：主界面，标注四个区域】

### 3.2 基本操作

一次移动分为两步：

**第一步**：点击一个栏位，拾取该栏位开口处连续同品种的一组动物。
被拾取的动物会抬高并加描边显示。

【截图：选中栏位，开口处一组动物被抬起】

**第二步**：点击另一个栏位放下。可放置的栏位会以虚线框提示。

放置需同时满足两个条件：
- 目标栏位为空，或目标栏位开口处为同一品种
- 目标栏位仍有剩余空间

若目标栏位剩余空间不足以容纳全部拾取的动物，则仅移动能够容纳的数量，
其余留在原栏位。

再次点击已选中的栏位可取消选择。

### 3.3 出栏

当某栏位集满同一品种的动物达到栏位容量时，该组动物自动出栏，
栏位随即清空并可继续使用。

【截图：出栏瞬间】

### 3.4 胜负判定

- **通关**：场上全部动物出栏
- **失败**：不存在任何合法移动

【截图：通关结算画面】

【截图：失败画面】

### 3.5 道具说明

| 道具 | 功能 | 可用条件 |
|---|---|---|
| 撤销 | 退回上一步操作，含已出栏的动物 | 已进行过至少一步操作 |
| 加栏 | 增加一个空栏位 | 游戏进行中 |
| 提示 | 由求解器给出下一步建议 | 当前局面存在解 |
| 牧羊犬 | 移除一只动物 | 仅在移除后局面仍可解时 |
| 重排 | 重新排列剩余动物，并保证可解 | 场上仍有动物 |

道具在当前不产生实际效果时按钮置为不可用状态。

【截图：道具栏，含可用与不可用状态】

### 3.6 关卡与评价

通关后按实际步数与求解器给出的最优步数比较给出星级评价：

- 步数不超过最优步数：三星
- 步数不超过最优步数的 1.35 倍：二星
- 其余：一星

## 四、软件结构说明

软件采用分层结构，各层职责明确、互不耦合：

```
游戏逻辑层   规则判定、关卡生成、求解器、状态管理
运营管理层   广告频次控制、虚拟道具、虚拟货币、权益管理
平台适配层   宿主平台接口封装，可替换
渲染呈现层   Canvas 绘制、布局计算、触摸命中判定
```

游戏逻辑层与运营管理层不直接调用任何宿主平台接口，全部通过平台适配层的
抽象接口访问，因此可在不同宿主环境间迁移。

## 五、注意事项

1. 本软件在网络不可用时仍可正常进行单机游戏
2. 广告展示受频次限制，且在广告加载失败时不影响游戏继续进行
3. 虚拟货币可通过游戏内多种途径免费获取，不依赖付费
