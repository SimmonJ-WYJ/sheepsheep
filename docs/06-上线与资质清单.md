# 上线与资质清单

> ⚠️ **免责声明：这份清单是工程视角的整理，不是法律意见。**
> 国内游戏资质政策（尤其版号）变动频繁，每一条都**必须**去下面列的官方渠道
> 核实当期口径。周期是经验区间，不是承诺。

## 一、为什么资质排在代码前面

代码写多快都没用 —— **版号决定你什么时候能开内购**，而版号的周期以月计。
所以正确的做法是：**资质流程和开发并行启动**，别等做完了才去办。

一句话判断你处在哪条路上：

```
想做内购（充值）？
├── 是 → 必须有版号 → 版号要通过有出版资质的发行商申报 → 周期以月计
└── 否 → 只做广告变现 → 门槛低得多，但当期政策要核实
```

## 二、需要办的东西，按顺序

### 1. 企业主体（营业执照）

小游戏做变现基本要企业账号，个人开发者做不了商业化。

- 如果还没有：注册一个公司，常见 1~2 周
- 已有就跳过

### 2. 抖音开放平台开发者账号 + 小游戏

- 入口：[抖音开放平台](https://developer.open-douyin.com/)
- 用企业主体注册、完成企业认证
- 创建「小游戏」类型的应用，拿到 **appid**（填进 `douyin/project.config.json`）
- 周期：数天 ~ 2 周（看认证审核）

### 3. 软件著作权登记（软著）

**这是申请版号的前置条件。**

- 办理机构：中国版权保护中心 / 各地版权局
- 需要：源代码前后各 30 页、软件说明书、申请表
- 周期：正常约 **30~60 个工作日**；加急 3~10 个工作日（额外收费）
- 建议：**现在就开始办**，等版号的时候正好用得上

> 本仓库的 `docs/` 那几篇可以直接当软件说明书的素材。

### 4. 版号（网络游戏审批文号）

**有内购就必须有。这是整条链路上最长的一环。**

- 审批机关：国家新闻出版署（NPPA）
- 关键点：**个人和一般公司不能自己提交**，必须通过有**出版资质**的单位（发行商）申报
- 周期：**数月起**，且不确定。没有任何人能给你承诺时间
- 现实做法：找发行商代理，他们出版号和买量，你分成（常见 3:7 ~ 5:5）

### 5. 变现能力开通

- 在抖音开放平台申请**流量主 / 广告变现**能力
- 逐个申请广告位，拿到 adUnitId，填进 `src/monetize/policy.ts` 的 `PLACEHOLDER_AD_UNITS`
- 激励视频 / 插屏 / Banner 是分开申请的

### 6. 虚拟支付开通（要版号）

- 拿到版号之后才能开通
- iOS 侧的虚拟支付另有限制，见 [`docs/05` 第零节](./05-盈利模型.md)
- 代码侧已经准备好：`paymentAvailability()` 运行时探测 + `iosPaymentEnabled` 远端开关

### 7. 合规必备件

- **防沉迷 / 实名认证**：接入平台提供的能力，未成年人时段和消费限制
- **隐私政策 + 用户协议**：需要有可访问的页面
- **内容审核**：素材、文案、话题标签都会过审

## 三、两条上线路径

### 路径 A：先上纯广告版（推荐用来验证玩法）

```
企业主体 → 开放平台账号 → 提交小游戏审核 → 开通广告变现 → 上线跑数据
                              ↓（并行）
                        办软著 → 找发行商 → 申版号 → 再开内购
```

好处：**几周内就能拿到真实的留存和 ARPDAU 数据**，而不是等几个月。
数据好看再去谈发行，谈判位置完全不同。

代码侧要做的：把内购入口整体关掉（下面第四节讲怎么关）。

⚠️ **"纯广告变现要不要版号"这条口径一直在变，务必先去开放平台确认。**

### 路径 B：直接找发行商

你出玩法和数据，发行商出版号 + 买量。

现在这个仓库正好就是谈发行的材料：
- 可玩 demo（`npm run dev`）
- **实测通过率曲线**（`npm run balance`）—— 这个东西大部分独立开发者拿不出来
- 完整的变现设计文档（`docs/03` `docs/05`）
- 85 个单测证明工程质量

## 四、没有版号时怎么关掉内购

代码里不需要删任何东西，**内购入口本来就是能整体关掉的**：

```ts
// 版号还没下来时，直接告诉引擎「这台设备不能充值」
const offers = new OfferEngine({ availability: 'unavailable' }, bootAt);
// offers.canPay === false → 所有充值弹窗和按钮一个都不出
```

关掉之后玩家仍然完全能玩：钻石靠 `economy.ts` 的免费通路获取
（签到 / 侧边栏 / 评星 / 每日挑战 / 看广告换钻，每日 275 钻），
足够撑起每天 1~2 次钻石复活 —— 这条路径有单测覆盖。

**所以纯广告版不是阉割版，是一个完整的游戏。**

## 五、上线前的技术检查清单

**打包**
- [ ] `douyin/project.config.json` 填了真实 appid
- [ ] `PLACEHOLDER_AD_UNITS` 换成真实广告位 id
- [ ] 首包体积达标（抖音有限制，超了要分包）
- [ ] 真机跑过 iOS + Android 各一台

**广告（真机验，模拟器不算）**
- [ ] 激励视频：看完 / 中途退出 / 无填充 三条分支
- [ ] 广告超时兜底（飞行模式模拟）
- [ ] 冷启动 180 秒静默、前 5 关无广告
- [ ] 跨天额度重置（改系统时间）

**内购（有版号才测）**
- [ ] 支付成功 / 取消 / 失败三条分支
- [ ] **服务端收据校验**（没有这个一定被刷）
- [ ] 权益到期（月卡）
- [ ] iOS 上支付入口确实不出现

**合规**
- [ ] 激励视频播放前有明确奖励告知
- [ ] 无诱导分享文案
- [ ] 防沉迷接入
- [ ] 隐私政策 / 用户协议可访问

**性能**
- [ ] 低端机帧率
- [ ] 求解器耗时不卡首帧（第 80 关生成约 20ms）
- [ ] `onHide` 暂停计时器和音频
